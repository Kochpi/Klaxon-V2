# Klaxon v2

Plateforme de covoiturage entre villes : proposer, rechercher et réserver des trajets, puis noter les conducteurs.

Refonte du projet PHP « Touche pas au Klaxon » avec une stack JavaScript.

## Stack

- **Front-end** : React (Vite)
- **Back-end** : Node.js / Express
- **Base relationnelle** : MySQL / MariaDB (utilisateurs, villes, trajets, réservations)
- **Base NoSQL** : MongoDB Atlas (avis)

## Structure

```
klaxon-v2/
├── client/      Application React
├── server/      API Express
├── database/    Scripts SQL (schéma + jeu de données)
└── NOTES.md     Journal des choix techniques
```
